# blockchain

## Setup

Para empezar a trabajar en el proyecto se necesita tener *uv* instalado y ejecutar
```sh
uv sync
```
*Esto creara el ambiente virtual e instalara las dependencias.*

Para añádir dependencias (librerias)
```sh
uv add <dependencia>
```

Para ejecutar el programa
```sh
uv run main.py
```
